# Approved Itch.io Art

This folder contains only final static exports approved for the NidoCardBattle itch.io page.

Keep untouched generated/source candidates under `assets/source/marketing/itch/`; do not use this folder as a scratch space.

Suggested final filenames:

- `cover.png` — store cover / thumbnail export;
- `hero.png` — wide page hero / banner export;
- `screenshot-01.png`, `screenshot-02.png`, ... — real gameplay captures only;
- `social-preview.png` — optional promotional share image.

Crop each export for its actual publishing slot and inspect it at both full size and thumbnail size before replacing an accepted file.
